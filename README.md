The RaceDay System is a database management system made to organize and manage running events. 
The system lets organizers create events, add race categories with different distances and manage runners or participants.
Runners can register and enroll race events and categories that are available to them. 
The system records race results like participants positions and finishing times. 
All in all the RaceDay System assists in organizing race events efficiently by storing and managing all race events, participants, enrollment, categories and result information in one database.  
There are two users in the system and they have different roles.
The first user is the organizer, who is responsible for managing the RaceDay system.
They can create and manage race events, add race categories, view participants enrollments and record or update race results.
